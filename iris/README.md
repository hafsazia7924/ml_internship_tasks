# Iris Classification Pipeline

A beginner machine learning project using the Iris dataset.

**What it does:**
- Loads the Iris dataset and explores it with a pairplot
- Scales features with StandardScaler
- Splits data 80/20 into train and test sets
- Trains Logistic Regression and Decision Tree models
- Evaluates both with accuracy, precision, recall, F1-score and confusion matrix heatmaps

**Tools:** Python, Pandas, Scikit-Learn, Seaborn, Matplotlib

**Note:** This is a learning project.
